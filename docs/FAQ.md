Goldenlum is an MB product developed under Fragment Cosmology. Its final public capability description will be published when the launch scope is approved.

Not yet. Goldenlum is currently in pre-launch.

https://goldenlum.com

Not yet. Pricing and commercial terms will be published only when formally announced.

Platform support has not yet been formally announced. Only explicitly published compatibility information should be treated as official.

## Where should bugs be reported?

Use GitHub Issues for reproducible product or documentation bugs once the relevant public component is available.

Use the Feature Request issue template. Requests are suggestions and do not imply roadmap commitment.

Use the Fragment Cosmology community repository or the support channels listed in SUPPORT.md.

Official release information will be published in GitHub Releases when Goldenlum reaches its first public release.
