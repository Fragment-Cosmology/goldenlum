# Goldenlum Support

## Before opening an issue

Please check:

- The latest public information on https://goldenlum.com
- The FAQ in docs/FAQ.md
- Existing GitHub Issues for duplicates
- The project status in docs/STATUS.md

## Bug reports

Use the Bug Report issue template for reproducible problems affecting a public Goldenlum component.

Include:

- What happened
- What you expected
- Exact steps to reproduce
- Platform and version information
- Screenshots or logs when safe to share

Do not post passwords, API keys, access tokens, personal data, private customer information, or security-sensitive secrets.

## Feature requests

Use the Feature Request template. Requests are evaluated as product input and do not create a roadmap commitment.

## General questions

For general community discussion, use the Fragment Cosmology community repository:

https://github.com/Fragment-Cosmology/community

## Security issues

Do not publish exploitable security details in a public issue.

Until a dedicated Goldenlum security-reporting channel is publicly announced, avoid posting sensitive exploit details publicly. A formal SECURITY.md and private reporting path will be added before public release.

## Scope

Support is currently limited to publicly released or publicly documented Goldenlum surfaces. Internal builds and unreleased capabilities are outside the public support scope.
